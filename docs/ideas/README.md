# Идеи и варианты / Ideas and Variants

## Русский

Здесь фиксируются предложения до их реализации. Для каждой идеи указываем проблему, предлагаемое решение, ожидаемый эффект, статус и связанные скриншоты.

Статусы: **предложено**, **на обсуждении**, **принято**, **отложено**, **отклонено**.

## English

This section captures proposals before implementation. Each idea should describe the problem, proposed solution, expected impact, status, and related screenshots.

Statuses: **proposed**, **under discussion**, **accepted**, **deferred**, **rejected**.
