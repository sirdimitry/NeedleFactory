# NeedleFactory — центр разработки / Development Hub

Это рабочее пространство для дневника разработки, визуальных вариантов, идей и решений по игре NeedleFactory.

This workspace stores development logs, visual concepts, ideas, and design decisions for NeedleFactory.

## Разделы / Sections

- [Дневник разработки / Development log](devlog/README.md)
- [Идеи и варианты / Ideas and variants](ideas/README.md)
- [Визуальные материалы / Visual references](visuals/README.md)

## Правила / Conventions

1. Каждая заметка: русский текст, затем английский перевод.
2. Отделяем идеи от принятых решений, а наблюдения — от подтверждённых ошибок.
3. Скриншоты и варианты сохраняем с датой и кратким описанием.
4. Историю не переписываем: новые решения фиксируем новыми записями.
5. Изменения в дневнике не означают изменения игрового кода.
