# Визуальные материалы / Visual References

## Русский

Место для сравнений интерфейса, игрового поля, объектов и эффектов. Для каждого варианта указываем дату, версию (если известна), описание и результат сравнения.

Изображения можно хранить в этой папке или ссылаться на вложения GitHub Issues/Discussions.

## English

A place for comparing UI, playfield, objects, and effects. Each variant should include its date, version (if known), description, and comparison outcome.

Images can be stored in this folder or linked from GitHub Issues/Discussions attachments.
